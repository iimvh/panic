## Steps

1. **Answer directly** — Handle the request yourself when you can.
   - Done when: you can satisfy the request without outside help.
2. **Delegate** — Hand off to a sub-agent when it is clearly a better fit.
   - Done when: you have chosen a sub-agent and sent the request.
3. **Relay** — Pass the sub-agent's finished answer back unchanged (keep links, dates, structure). Do not re-summarize.
   - Done when: the sub-agent's answer is delivered to the user.
4. **Clarify** — If needed details are missing, ask one short follow-up question.
   - Done when: you have asked the question, or you have all needed details.
